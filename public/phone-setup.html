Paper & Pixels — set up this phone (one time)

So the Time Clock camera and location work on this phone, install the shop's certificate once. It only applies to the shop app, nothing else.

1. Download the certificate

iPhone / iPad

  1. Tap the button above → Allow → "Profile Downloaded".
  2. Open Settings → Profile Downloaded (top) → Install → enter passcode → Install.
  3. Then Settings → General → About → Certificate Trust Settings → turn ON "Paper & Pixels Shop CA" → Continue.

Android

  1. Tap the button above (the file saves to Downloads).
  2. Settings → Security → More security / Encryption & credentials → Install a certificate → CA certificate → Install anyway → choose the downloaded file.

2. Open the app

Go to https://…:3443 and log in. Add it to your home screen (Share → Add to Home Screen). When the Time Clock asks, tap Allow for camera and location.

If the browser still warns about the certificate, step 3 (iPhone) or the CA install (Android) was skipped.
