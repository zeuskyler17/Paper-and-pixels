Paper & Pixels — set up this phone or PC (one time)

So the Time Clock camera and location work on this phone or computer, install the shop's certificate once. It only applies to the shop app, nothing else.

1. Download the certificate

iPhone / iPad

  1. Tap the button above → Allow → "Profile Downloaded".
  2. Open Settings → Profile Downloaded (top) → Install → enter passcode → Install.
  3. Then Settings → General → About → Certificate Trust Settings → turn ON "Paper & Pixels Shop CA" → Continue.

Android

  1. Tap the button above (the file saves to Downloads).
  2. Settings → Security → More security / Encryption & credentials → Install a certificate → CA certificate → Install anyway → choose the downloaded file.

Windows PC — Chrome or Edge

  1. Click the button above, then open the downloaded Paper-and-Pixels-CA.crt.
  2. Install Certificate… → Current User → Next → Place all certificates in the following store → Browse → Trusted Root Certification Authorities → OK → Next → Finish → Yes on the security warning.
  3. Close and reopen the browser.

Windows PC or Mac — Firefox

  1. Click the button above (the file saves to Downloads).
  2. Firefox menu ☰ → Settings → search certificates → View Certificates… → Authorities tab → Import… → choose the downloaded file.
  3. Tick Trust this CA to identify websites → OK → OK.

2. Open the app

Go to https://…:3443 and log in. On a phone, add it to your home screen (Share → Add to Home Screen). When the Time Clock asks, tap Allow for camera and location.

If the browser still warns about the certificate, the trust step above was skipped (iPhone: Certificate Trust Settings; Android: CA install; PC: Trusted Root / Firefox Authorities).
